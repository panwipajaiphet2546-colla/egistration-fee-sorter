# คัดแยกผู้ชำระค่าลงทะเบียน

เครื่องมือของงานทะเบียน ใช้คัดแยกรายชื่อผู้ชำระค่าลงทะเบียน (จากไฟล์ Excel ของงานการเงิน) ตามระดับชั้น สาขาวิชา และกลุ่มเรียน

## ปัญหาที่แก้

ไฟล์รับชำระเงินที่งานการเงินส่งมามีแค่รหัสและชื่อนักเรียน ไม่บอกว่าใครอยู่ชั้นไหน สาขาอะไร งานทะเบียนต้องมานั่งแยกเอง เครื่องมือนี้จับคู่ไฟล์การเงินกับรายชื่อนักเรียนทั้งหมด แล้วแยกให้อัตโนมัติ

## ความสามารถ

- นำเข้ารายชื่อนักเรียนจาก **รายงานรายชื่อนักเรียนนักศึกษาแยกตามกลุ่ม (RMS)** ได้หลายไฟล์พร้อมกัน ระบบอ่านระดับชั้น กลุ่มเรียน และสาขาจากหัวรายงานของแต่ละชีตเอง
- นำเข้าจากไฟล์ Excel ทั่วไปได้ โดยเลือกคอลัมน์เอง
- รวมชื่อสาขาที่เป็นสาขาเดียวกัน เช่น "ช่างไฟฟ้า" กับ "ไฟฟ้า" และตัดเลขห้องออกจากชื่อสาขา เช่น "บัญชี 1/3" (แก้ได้ที่ `DEPT_ALIASES` ใน `index.html`)
- อ่านไฟล์จากฝ่ายการเงินได้ทุกชีตในครั้งเดียว (เช่น แยกชีตตามวันที่รับเงิน) และหาคอลัมน์รหัส ชื่อ เลขที่ใบเสร็จ วันที่ และจำนวนเงินเอง ไม่ต้องเลือกคอลัมน์
- จับคู่ไฟล์การเงินด้วยรหัสนักศึกษา เลขประจำตัวประชาชน หรือชื่อ-สกุล
- สถานะชำระเงิน 3 แบบ: ชำระแล้ว ผ่อนผัน ยังไม่ชำระ พร้อมเลขที่ใบเสร็จ วันที่ และจำนวนเงิน
- เพิ่ม แก้ไข หรือลบนักศึกษาทีละคน และตั้งสถานะผ่อนผันพร้อมหมายเหตุได้
- กรองตามชั้นปี สาขาวิชา สถานะ และค้นหาชื่อ / รหัส / ห้อง
- สรุปจำนวนตามระดับชั้นและสาขา และแสดงรายการในไฟล์การเงินที่หาไม่พบในรายชื่อ
- ส่งออก Excel: ชีตสรุป ชีตแยกตามชั้นและสาขา ชีตยังไม่ชำระ ชีตผ่อนผัน และชีตรายการที่ไม่พบในรายชื่อ

## วิธีใช้

1. เปิด `index.html` ในเบราว์เซอร์
2. กด "นำเข้ารายชื่อจาก RMS" แล้วเลือกไฟล์รายงานรายชื่อแยกตามกลุ่มของทุกชั้นปีพร้อมกัน (ทำครั้งเดียวต่อปีการศึกษา)
3. ในช่อง "อัปเดตสถานะชำระเงินจากไฟล์ Excel ของฝ่ายการเงิน" เลือกไฟล์ แล้วกด "ประมวลผลอัปเดตข้อมูล"
4. กรองดูรายชื่อ หรือกด "สรุป / Excel" เพื่อดูสรุปและดาวน์โหลดไฟล์

## การเก็บข้อมูล

- ตัวใช้งานจริงเปิดผ่าน Claude Artifact ซึ่งมีฐานข้อมูลออนไลน์ในตัว เจ้าหน้าที่ที่ได้รับสิทธิ์เห็นข้อมูลชุดเดียวกัน
- ถ้าเปิด `index.html` จากเครื่องหรือจาก GitHub Pages ข้อมูลจะถูกเก็บในเบราว์เซอร์ของเครื่องนั้น (localStorage) ไม่หายเมื่อรีเฟรช แต่ไม่ซิงก์ไปเครื่องอื่น ครั้งแรกหน้าเว็บจะแสดงข้อมูลตัวอย่าง (สมมติ)
- ไฟล์จากฝ่ายการเงินประมวลผลในเบราว์เซอร์ ไม่ถูกส่งไปที่ใด

## ข้อควรระวัง

ห้ามอัปโหลดไฟล์รายชื่อนักเรียนหรือไฟล์จากงานการเงินขึ้น GitHub เพราะมีชื่อและเลขประจำตัวประชาชนของนักเรียน ไฟล์ `.gitignore` กันนามสกุล `.xlsx` `.xls` และ `.csv` ไว้แล้ว

## เทคโนโลยี

- HTML, CSS, JavaScript ในไฟล์เดียว
- [SheetJS](https://sheetjs.com/) สำหรับอ่านและเขียนไฟล์ Excel
- ฟอนต์ Anuphan และ IBM Plex Sans Thai จาก Google Fonts
