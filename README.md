# คัดแยกผู้ชำระค่าลงทะเบียน

เครื่องมือของงานทะเบียน ใช้คัดแยกรายชื่อผู้ชำระค่าลงทะเบียน (จากไฟล์ Excel ของงานการเงิน) ตามระดับชั้น สาขาวิชา และกลุ่มเรียน

## ปัญหาที่แก้

ไฟล์รับชำระเงินที่งานการเงินส่งมามีแค่รหัสและชื่อนักเรียน ไม่บอกว่าใครอยู่ชั้นไหน สาขาอะไร งานทะเบียนต้องมานั่งแยกเอง เครื่องมือนี้จับคู่ไฟล์การเงินกับรายชื่อนักเรียนทั้งหมด แล้วแยกให้อัตโนมัติ

## ความสามารถ

- นำเข้ารายชื่อนักเรียนจาก **รายงานรายชื่อนักเรียนนักศึกษาแยกตามกลุ่ม (RMS)** ได้หลายไฟล์พร้อมกัน ระบบอ่านระดับชั้น กลุ่มเรียน และสาขาจากหัวรายงานของแต่ละชีตเอง
- นำเข้าจากไฟล์ Excel ทั่วไปได้ โดยเลือกคอลัมน์เอง
- รวมชื่อสาขาที่เป็นสาขาเดียวกัน เช่น "ช่างไฟฟ้า" กับ "ไฟฟ้า" และตัดเลขห้องออกจากชื่อสาขา เช่น "บัญชี 1/3" (แก้ได้ที่ `DEPT_ALIASES` ใน `index.html`)
- จับคู่ไฟล์การเงินด้วยรหัสนักเรียน เลขประจำตัวประชาชน หรือชื่อ-สกุล
- สรุปจำนวนผู้ชำระและผู้ค้างชำระตามระดับชั้นและสาขา (แยกถึงกลุ่มเรียนได้)
- แสดงรายการในไฟล์การเงินที่หาไม่พบในรายชื่อ เพื่อให้ตรวจสอบ
- ส่งออก Excel: ชีตสรุป ชีตแยกตามชั้นและสาขา ชีตค้างชำระทั้งหมด และชีตรายการที่ไม่พบในรายชื่อ

## วิธีใช้

1. เปิด `index.html` ในเบราว์เซอร์
2. กล่องที่ 1: นำเข้ารายชื่อนักเรียน (ไฟล์ RMS ของ ปวช.1 ถึง ปวส.2)
3. กล่องที่ 2: อัปโหลดไฟล์รับชำระเงินจากงานการเงิน
4. ดูผลในตาราง แล้วกด "ดาวน์โหลด Excel ที่แยกแล้ว"

## การเก็บข้อมูล

- ตัวใช้งานจริงเปิดผ่าน Claude Artifact ซึ่งมีฐานข้อมูลในตัว รายชื่อนักเรียนนำเข้าครั้งเดียวแล้วใช้ได้ทุกภาคเรียน และอ่านได้เฉพาะผู้ที่ได้รับสิทธิ์
- ถ้าเปิด `index.html` จากเครื่องหรือจาก GitHub Pages จะไม่มีฐานข้อมูล รายชื่อที่นำเข้าจะใช้ได้เฉพาะตอนเปิดหน้านั้น และหน้าเว็บจะเริ่มด้วยข้อมูลตัวอย่าง (สมมติ)
- ไฟล์จากงานการเงินประมวลผลในเบราว์เซอร์เท่านั้น ไม่ถูกส่งไปที่ใด

## ข้อควรระวัง

ห้ามอัปโหลดไฟล์รายชื่อนักเรียนหรือไฟล์จากงานการเงินขึ้น GitHub เพราะมีชื่อและเลขประจำตัวประชาชนของนักเรียน ไฟล์ `.gitignore` กันนามสกุล `.xlsx` `.xls` และ `.csv` ไว้แล้ว

## เทคโนโลยี

- HTML, CSS, JavaScript ในไฟล์เดียว
- [SheetJS](https://sheetjs.com/) สำหรับอ่านและเขียนไฟล์ Excel
- ฟอนต์ Anuphan และ IBM Plex Sans Thai จาก Google Fonts
